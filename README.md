# Library Management System

## 📌 Project Overview
The Library Management System is a console-based application developed in C++ using Object-Oriented Programming (OOP) and File Handling concepts.  
This project helps in managing books, searching books, issuing and returning books, and maintaining library records efficiently.

---

# 🎯 Objective
To develop a Library Management System that efficiently manages books, members, and borrowing records using structured or object-oriented programming.

---

# 🚀 Features
- Add New Books
- Display Book Details
- Search Book by Title
- Search Book by Author
- Issue Books
- Return Books
- Store Records Using File Handling
- Menu Driven Application

---

# 🛠 Technologies Used
- Language: C++
- Concepts Used:
  - Classes & Objects
  - Encapsulation
  - File Handling
  - Functions
  - Conditional Statements
  - Loops

# ▶ How to Run the Project

## Step 1: Install Compiler
Install any C++ compiler such as:
- MinGW
- Dev C++
- Code::Blocks
- VS Code with C++ Extension

---

## Step 2: Save the File

Save the source code as:

```text
library.cpp
```

---

## Step 3: Compile the Program

Open terminal and run:

```bash
g++ library.cpp -o library
```

---

## Step 4: Run the Program

### Windows
```bash
library.exe
```

### Linux / Mac
```bash
./library
```
